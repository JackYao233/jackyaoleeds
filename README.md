# Jack Yao’s Website

A student portfolio with About Me, Weekly Reflections and Photography pages.

## Files

- `index.html`: homepage
- `about.html`: About Me
- `reflections.html`: weekly reflection directory
- `week2.html`: Week 2 reflection
- `photography.html`: photography gallery
- `style.css`: shared stylesheet
- `images/`: images used by the pages

## Upload

Upload the contents of this folder to your GitHub Pages repository, keeping `index.html` at the site root and preserving the `images/` folder structure. No installation or build step is needed.

Open `index.html` in a browser to preview locally. Google Fonts are loaded online; system fonts are used if they are unavailable.
